# مجلد خطوط المدونة (`public/fonts`)

يدعم الموقع الآن **نظام الخطوط الثلاثي** بحيث يمكنك تخصيص خط مستقل لكل وظيفة بصرية في المدونة:

1. **خط العناوين الرئيسية الكبرى (`--font-display`)**:
   - يُطبّق تلقائياً على: عناوين المقالات الرئيسية والفرعية (`h1`, `h2`, `h3`) والشعار وعناوين الأقسام.
   - الاسم الافتراضي للملف: `Display-Bold.woff2` (أو `.ttf`).

2. **خط القوائم والأزرار والتواريخ (`--font-ui`)**:
   - يُطبّق تلقائياً على: شريط التنقل، القوائم، الأزرار، التصنيفات، التواريخ، أوقات القراءة، وحقول البحث.
   - الأسماء الافتراضية للملفات: `UI-Regular.woff2` و `UI-Bold.woff2` (أو `.ttf`).

3. **خط المتن والقراءة الطويلة (`--font-prose`)**:
   - يُطبّق تلقائياً على: نص المقال الكامل، الفقرات، الاقتباسات، والقوائم داخل المقال.
   - الأسماء الافتراضية للملفات: `Prose-Regular.woff2` و `Prose-Bold.woff2` (أو `.ttf`).

> **ملاحظة**: يمكنك أيضاً رفع ملفات خطوطك بأي اسم تريده داخل هذا المجلد (`/public/fonts/`) وإخباري بأسمائها، وسأربط كل ملف بالوظيفة التي تحددها فوراً في `/src/index.css`.
